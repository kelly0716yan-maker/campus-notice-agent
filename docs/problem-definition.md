# 问题定义（草稿，带【】的地方需要你补充）

## 1. 目标用户
高校本科生，尤其是同时加入多个班级群、学院群、社团群的同学。
【补充：你的访谈对象里，典型用户是什么样？比如"大三、加了8个以上群、有社团职务"】

## 2. 典型场景
同学每天在多个群里收到通知，混杂着与自己无关的信息，重要的截止时间容易被淹没。
【补充：1–2 个你自己或访谈对象遇到的真实例子，越具体越好（去掉姓名）】

## 3. 现状痛点
- 通知分散在多个群，刷屏后找不到
- 要自己判断"这条和我有没有关系"
- 截止时间靠记忆或手动记备忘录
【补充：用访谈结论验证或修改以上三条，写上"X/5位受访者提到……"】

## 4. 现有做法与不足
【补充：同学现在用什么办法？比如截图、群公告、备忘录、日历。各有什么不足？】

## 5. 为什么用 AI
通知格式不固定、表述口语化，用规则或模板难以覆盖；大模型擅长从非结构化文本中抽取信息并做判断。
【补充：访谈里有没有同学提到"每次都要读完整段才能找到时间"这类线索？】

## 6. 成功标准（V0.1）
- 关键字段（事项、时间、对象）抽取准确率 ≥ 【目标，如85%】
- 通知里没有的信息不编造（"未提及"使用正确）
- 【补充：用户侧指标，如"愿意继续使用的受访者占比"】
